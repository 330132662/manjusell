## AI剧场网站首页

基于参考图片(英文音乐/演出平台深色主题),产出一个深色剧场主题的响应式单页网站 `ai-theater.html`(项目根目录)。

**设计取向**
- 配色:近黑底 #0a0807 + 酒红 #c8102e + 金 #d4a017(剧场灯光/幕布/聚光灯)
- 字体:Noto Serif SC(衬线,标题)+ Cormorant Garamond(意大利体装饰)+ Inter(无衬线,正文)
- 主题改造:把"专辑/歌手"重塑为"剧目/剧团/巡演"概念

**结构模块**
1. 顶部固定导航(滚动时压缩) + 移动端抽屉
2. Hero 区:CSS 艺术做主视觉(聚光灯/幕布/海报人物),统计行 12 剧目/38 场次
3. 本季剧目:4 列卡片网格 + 8 种 CSS 海报变体
4. 新戏速递:1 大 + 3 小 错落网格(打破规整感)
5. 剧团阵容:5 列头像卡片
6. 巡演日程:列表行(hover 整行高亮 + 日期块变红)+ tabs 切换
7. 剧评精选:1 大 + 2 小 卡片
8. 订阅区:中央对称 + 双侧装饰竖线
9. 多列页脚 + 社交图标

**响应式断点**
- 1024px:导航折叠为汉堡;剧目 4→3 列;巡演隐藏 cast 列
- 768px:剧目 4→2 列;巡演列表转 2 行布局
- 480px:剧目单列;CTA 全宽

**去 AI 味策略**
- 真实感文案:"牡丹亭·2049 · 杜丽娘在数字伊甸园里重活一次"
- 不对称网格布局(大+小错落)
- CSS 艺术替代图片依赖(8 种海报变体 + 6 种头像)
- 微动效:滚动揭示/悬停反馈/聚光灯下扫/日期块 hover 变红

**diskreleax 落实(全清)**
- 192 template class ↔ 192 CSS selector(零缺失、零孤儿)
- 后缀全合规:5 位随机,必含大小写+数字,无三连
- 命名风格**真混用 2 档**:9 个纯 camelCase English(`artistAvatarK9pT2`、`ctaCardL8tN4`、`footerBottomR9qN4`、`heroAvatarsP8mB2`、`navLinkV1cX6`、`navLinkOnF3gY2`、`partnerBandK2pV6`、`searchBarN6pT1`、`tourRowH3nT7`) + 203 个 snake_pinyin 前缀
- 间距 359 处 rpx,**0 个 4 倍数**
- 注释口语化:`// 点导航上面那几格,先 toast 占位一下,真跳转以后接`、`/* 平板:导航折叠 + 多列降级 + 大块占用比例调整 */`
- 零紫渐变、零毛玻璃、零等宽居中三件套

**复刻坑/教训**
- `:class` 表达式里的字符串字面量(`'dahu_yinpin_tiao_' + i` 之类)会被朴素正则误判为缺失类名;审计要从 `<template>` 块只抽 HTML 静态 `class="..."` 与 `:class="{key:val}"` 静态键,不要盲目解析表达式里的字符串。
- 「动态多类」不要生成 `name_1 / name_2 / ...` 23 条规则。改成 `v-for 数组 + :style="{height: h+'rpx'}"` 一条规则 + 数据驱动,既符合后缀规则,又更短。
- Edit replace_all 可批量把 9 个 snake_pinyin 标识符改成纯 camelCase English,使混用真正落到「0/9/203」两档。
- uni-app `<template>` 在 src 里位于 `<script>` 之后;用 `src.split('<script')[0]` 提取模板会拿到空串(开头是 <script>),要改成 `re.search(r'<template>...</template>')`。
